# TTworks 商品化・自動化運用

## 基本方針
TTworksの商品化は、既存のLINEスタンプ資産を再利用し、在庫を持たない受注生産を優先する。

### 自動で進めてよい作業
- 既存画像・制作台帳の確認
- 商品化候補の選定
- グッズ用画像の準備方針決定
- 商品名、説明文、英語文、タグの作成
- 推奨価格案・利益案の作成
- SUZURI/UP-T向け登録準備
- SNS告知文案の作成
- 販売後の売れ筋整理・次展開候補の選定
- 無料かつ可逆な下書き・整理・記録更新

### 必ず本人決裁で止める作業
- 支払い・決済
- 有料プラン加入
- 契約・規約同意
- 最終公開・販売開始
- 金銭条件に直接影響する重要な価格変更
- 権利・ライセンス等の承認
- 重要な外部権限付与

## サービスの役割
- UP-T: Tシャツ、パーカー、スウェット、マグ、エコバッグ等のアパレル中心
- SUZURI: ステッカー、アクキー、缶バッジ、アクスタ等のキャラクターグッズ中心
- 将来候補: Shopify + Printful（売れ筋確立後の自社EC・海外展開）

## 第1弾
### TTworks FISHING STICKER COLLECTION #01
対象: FISHシリーズ既存画像

優先順位:
1. 既存完成画像を使う
2. production_manifestで生成済みを確認
3. visual_passedの確認
4. 問題がある画像のみ修正候補
5. 重複生成しない

初期商品数: 10点

### FISHキャラクター
- FISH-001: 釣りギャル / ギャル語
- FISH-002: 眼鏡のアングラー / 標準語
- FISH-003: 関西アングラーおじさん
- FISH-004: 制作台帳・キャラクター台帳を正本として確認

## 1商品あたりの準備物
1. 元画像
2. グッズ用透過PNG
3. 商品名
4. 日本語説明
5. 英語説明
6. タグ
7. 推奨価格案
8. 展開先
9. SNS投稿文
10. 公開前ステータス

## 進行ルール
- 完成済み画像は再生成しない
- 生成枠を無駄に消費しない
- LINE用画像とグッズ用画像を同時資産化する
- 商品登録完了後も最終公開前で本人確認を入れる
- 1作品単位で識別できる名称を付けて管理する
