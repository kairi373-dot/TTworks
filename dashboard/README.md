# TTworks Control Center

TTworksの制作・販売準備・Web・SNSを一元管理するための静的ダッシュボードです。

## 現在の範囲
- LINEスタンプ制作プロジェクトの進捗表示
- TTworksグッズ/Web/SNSの管理
- 担当AIの役割表示
- 次アクション表示
- キャラクター台帳の初期表示
- スマートフォン優先のレスポンシブUI

## 安全ルール
このダッシュボードから契約、決済、販売申請、公開承認などの不可逆操作は自動実行しません。
将来外部サービスと接続する場合も、承認が必要な工程は人の確認を挟む設計にします。

## 次の実装候補
1. JSON/CSVベースの制作台帳
2. 完成済み画像と制作番号の重複チェック
3. LINE登録名を使った作品単位の枝分かれ管理
4. GitHub Issuesとの進捗同期
5. Canva/販売サイト/SNS連携用の承認キュー
6. 完成・申請・販売中ステータスの自動集計

## 確認方法
`dashboard/index.html` をブラウザで開くと表示できます。
