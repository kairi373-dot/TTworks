# TTworks Website Structure

## Purpose
TTworksのオリジナル商品を紹介し、LINE STOREやグッズ販売先への導線をつくる公式サイト。

## Initial information architecture
1. Home / Hero — ブランドの第一印象と商品への導線
2. Products — Wear / Goods / LINE Stickers
3. LINE Stickers — スタンプシリーズ紹介
4. About — TTworksのブランド紹介
5. Online Shop — 外部販売ページへの導線

## Design direction
- Mobile-first responsive design
- Simple, editorial, clean visual language
- Japanese-first copy
- English section labels and semantic HTML to make later localization easier
- No framework dependency in the first version; plain HTML/CSS/JS keeps the initial site lightweight

## Planned expansion
- 実際の商品画像と商品詳細
- LINE STORE / UP-T等の販売URL
- 個別商品ページまたはコレクションページ
- SNSリンク
- 英語コンテンツ切替
- OGP / favicon / analytics
